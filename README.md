# 🌦 Tropometrics Infrastructure Project

Dit GitHub-organization repository bevat de documentatie, configuraties en bronbestanden voor het **Tropometrics Infrastructure Project**, uitgevoerd in het kader van een HBO-opleiding aan **De Haagse Hogeschool (HHS)**.

Het project richt zich op het ontwerpen, implementeren en documenteren van een **betrouwbare, schaalbare en veilig beheerde IT-infrastructuur** ter ondersteuning van de Tropometrics-diensten, waaronder monitoring, observability, cloud-native applicaties en telefonie.

---

## 🎯 Projectdoel

Het doel van dit project is het realiseren van een toekomstbestendige infrastructuur die:

- Hoge beschikbaarheid en redundantie biedt  
- Voldoet aan vastgestelde functionele en niet-functionele eisen (PvE)  
- Gebruikmaakt van gangbare standaarden en best practices  
- Ondersteuning biedt voor moderne technologieen zoals containerization, Kubernetes en CI/CD  
- Inzicht geeft in prestaties, beschikbaarheid en incidenten via monitoring en logging  

---

## 🧩 Scope van het project

Binnen deze repository vallen onder andere:

- 📐 Architectuur- en netwerkontwerpen  
- 📄 Programma van Eisen (PvE)  
- ⚙ Netwerk- en serverconfiguraties  
- ☸ Kubernetes / K3s manifests en GitOps-configuraties  
- 📊 Monitoring- en observability-configuraties (bijv. Grafana, Prometheus, Uptime Kuma)  
- ☎ Telefonie- en IVR-documentatie  
- 📚 Onderbouwingen met standaarden en best practices  

---

## 🛠 Gebruikte technologieen (selectie)

- Linux (Alpine, Debian-based)  
- Docker & Docker Compose  
- Kubernetes / K3s  
- ArgoCD (GitOps)  
- Prometheus & Grafana  
- SNMP / monitoring tooling  
- Reverse proxy (HTTP(S))  
- VoIP / IVR-telefonie  
- VLAN-segmentatie, routing en VPN-technologieen  

---

## 📌 Opmerking

Dit project is opgezet als **Proof of Concept (PoC)** en oplevering binnen een onderwijscontext. Niet alle keuzes zijn bedoeld voor directe productie-implementatie, maar zijn technisch onderbouwd en reproduceerbaar.
